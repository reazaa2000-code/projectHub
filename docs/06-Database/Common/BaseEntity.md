# Base Entity Specification

Version: 1.0

Status: Approved

---

# Purpose

BaseEntity contains common fields shared by all persistent entities.

This entity is not stored as a separate table.

All business entities inherit from BaseEntity.

---

# Common Fields

| Column | SQL Type | Null | Description |
|----------|----------|------|-------------|
| Id | bigint | No | Primary Key |
| CreatedAt | datetime2 | No | Creation timestamp |
| UpdatedAt | datetime2 | Yes | Last update timestamp |
| CreatedBy | bigint | Yes | User who created the record |
| UpdatedBy | bigint | Yes | User who last updated the record |

---

# Future Fields

The following fields are intentionally deferred.

- DeletedAt
- DeletedBy
- IsDeleted
- RowVersion

These will be introduced when Soft Delete and Optimistic Concurrency are implemented.

---

# Design Rules

- Every persistent entity inherits from BaseEntity.
- Id is generated by the database.
- CreatedAt is generated automatically.
- UpdatedAt is updated automatically.
- CreatedBy and UpdatedBy reference User.
