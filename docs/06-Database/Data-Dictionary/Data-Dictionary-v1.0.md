# Purpose

This document defines the canonical data dictionary for the Core Domain.

Infrastructure entities such as User, Role and Permission are intentionally outside this Core Domain dictionary.

# Canonical Terminology Notes

- `Open` replaces `Open for Enrollment`.
- `InProgress` replaces `In Progress`.
- `Completed` is the normal completed Class lifecycle state; `Cancelled` is used when a Class is cancelled.
- `Registered` is the initial Enrollment status.
- `Pending Payment` is not an Enrollment status in v1.
- `Dropped` is the canonical v1 term instead of `Withdrawn`.
- Student Status is limited to `Active` and `Inactive`.
- Delivery Type codes are `InPerson`, `Online`, `Corporate`, `Hybrid`.

This document is the official data dictionary baseline for EF Core entities, Fluent API configuration and database migrations.
