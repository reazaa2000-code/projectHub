# Enrollment Status

Enrollment Status represents the current lifecycle state of a student's registration in a Class.

The following statuses are supported.

| Status | Description |
|----------|-------------|
| Pending Payment | Registration has been created but payment has not yet been confirmed. |
| Enrolled | Student is officially enrolled in the Class. |
| Cancelled | Registration has been cancelled before the Class starts. |
| Completed | Student has successfully completed the Class. |
| Failed | Student has not successfully completed the Class. |
| Withdrawn | Student voluntarily withdrew from the Class after enrollment. |

---

# Status Lifecycle

Pending Payment
        │
        ├────────────► Cancelled
        │
        ▼
Enrolled
    │
    ├────────────► Withdrawn
    │
    ▼
Completed
    │
    └────────────► Failed

---

# Business Rules

- Every Enrollment must always have exactly one Status.
- Initial Status depends on Tuition.
- Tuition = 0 → Initial Status = Enrolled.
- Tuition > 0 → Initial Status = Pending Payment.
- Completed and Failed are terminal states.
- Cancelled and Withdrawn terminate the Enrollment.

# Enrollment Date

Enrollment Date represents the exact date and time when an Enrollment record is created.

---

# Definition

Enrollment Date is automatically generated by the system.

It records the official registration timestamp.

---

# Rules

- Automatically generated.
- Cannot be edited.
- Cannot be deleted.
- Stored using system date and time.
- Used for reporting and auditing.
- Used for refund calculations in future Financial module.

---
